# FamilienEssensPlaner V25

V25: mobile Oberfläche mit Profil-PLZ, automatischem Angebotsvergleich, Rezepten und Einkaufsliste.

**Wichtig:** GitHub Pages kann nicht zuverlässig alle Händlerseiten als Live-Datenquelle auslesen. V25 nutzt deshalb einen klar gekennzeichneten Vergleichs-/Demo-Katalog und verlinkt auf die offiziellen Händlerangebote. Für echte Live-Preise ist ein zulässiger API-/Datenfeed bzw. Backend je Händler erforderlich.

Upload:
1. `index.html` ersetzen.
2. Ordner `data` hochladen.
3. GitHub Pages auf `main` / root veröffentlichen.
4. Seite neu laden.
