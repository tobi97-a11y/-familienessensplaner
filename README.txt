FamilienEssensPlaner Premium PWA
--------------------------------
Diese Version ist als mobile-first Web-App/PWA vorbereitet.
Sie kann auf einer HTTPS-Webseite veröffentlicht und auf Android/iPhone zum Startbildschirm hinzugefügt werden.

Wichtig:
Eine öffentlich erreichbare Live-URL kann ich aus diesem Chat nicht selbst hosten. Das Paket ist aber bereit für einen statischen Webhost.
Für die echte automatische Händler-Angebotsaktualisierung muss zusätzlich ein Backend mit zulässigen APIs/Feeds bzw. freigegebenen Datenquellen angeschlossen werden.
