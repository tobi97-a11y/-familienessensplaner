FAMILIENESSENSPLANER – NEUAUFSETZEN

1. ZIP-Datei entpacken.
2. Den Inhalt des Ordners "FamilienEssensPlaner" in dein GitHub-Repository hochladen.
3. Wichtig: index.html muss direkt im Hauptverzeichnis des Repositorys liegen.
4. Der Ordner "images" muss direkt neben index.html liegen.
5. In GitHub auf "Commit changes" klicken.
6. GitHub Pages muss auf den Branch "main" und den Root-Ordner (/) zeigen.
7. Danach die GitHub-Pages-Adresse öffnen und Safari einmal neu laden.

- Familienprofil
